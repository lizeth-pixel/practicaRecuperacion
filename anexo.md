**1. MariaDB Dump (mariadb-dump)**

Es una herramienta que permite generar copias de seguridad lógicas de bases de datos. Exporta la estructura y los datos mediante instrucciones SQL que posteriormente pueden restaurarse.

**2. --single-transaction**

Es una opción de mariadb-dump que permite realizar una copia consistente de las tablas transaccionales, especialmente InnoDB, utilizando una sola transacción.

Ayuda a evitar bloqueos durante el proceso de respaldo, aunque no garantiza la misma consistencia para tablas que no utilizan motores transaccionales.

**3. --databases**

Es una opción utilizada al exportar bases de datos. Incluye instrucciones SQL para crear y seleccionar la base de datos durante la restauración.

Cuando no se utiliza, es posible importar el contenido en otra base de datos previamente creada con un nombre diferente.

**4. CHECKSUM TABLE**

Es un comando de MariaDB que permite obtener un valor de comprobación de una tabla.

Se utiliza para comparar información entre dos tablas y ayudar a detectar diferencias después de una migración.

**5. COUNT(*)**

Es una función SQL que permite contar la cantidad de registros que contiene una tabla o consulta.

**6. SHOW CREATE TABLE**

Es una instrucción que permite consultar la definición de una tabla, incluyendo sus columnas, claves y restricciones.

**7. Integridad referencial**

Es un conjunto de reglas que garantiza que las relaciones entre tablas sean válidas.

**8. GitHub**

Es una plataforma que permite alojar repositorios de proyectos y administrar archivos mediante el sistema de control de versiones Git.

**9. Migración de bases de datos**

Es el proceso de trasladar una base de datos desde un origen hacia un destino, conservando su estructura, información y relaciones.
